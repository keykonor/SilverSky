# 现实一致性与模拟真实性检查表

逐项核对界面文案、图例、路线卡、地图标记、交互状态和来源说明；记录对应 `PlanningResult` 字段、数据状态、截图/运行证据及用户可能产生的推断。

| 显示对象 | 不可跨越的语义边界 | 需检验的问题 |
| --- | --- | --- |
| POI 坐标 | `POI` 中心点不等于入口/上车点 | 是否明示定位精度与入口未知？ |
| 静态道路快照 | 道路模型不等于实时、门到门或无障碍导航 | 是否把估算时长/距离说成实时可达？ |
| 模拟接驳 | 直线参考不等于可通行道路 | 线型与说明是否清晰？ |
| 模拟起降点 | 虚构坐标不等于真实设施 | 名称、图标、背景楼块是否使人误认已建成？ |
| 模拟空中线 | `SIMULATED_AIR_CORRIDOR` 不等于运营航线/可飞路线 | 切换视角后模拟标记是否仍可见？ |
| 视觉高度 | 画面派生高度不等于批准高度或海拔实测 | 是否被表达成真实飞行层或监管许可？ |
| Safety `REJECT` | 可查看不等于可推荐/可乘坐 | 选中态、颜色与主按钮是否造成认可错觉？ |
| 地图背景 | 城市楼块或地形不等于路线证据 | 来源、坐标转换、失败状态与回退是否清晰？ |

如有数据来源缺失，记 `DATA_UNAVAILABLE` 或 `NOT_VERIFIED`，不由地图画面补足。`safety-data-integrity` 负责安全与来源规则，`silver-sky-geospatial-review` 负责几何和坐标核查；本表负责用户最终会如何理解。
