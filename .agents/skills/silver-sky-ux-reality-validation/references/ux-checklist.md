# 任务完成与老年用户体验检查表

按具体用户任务填写：场景、起始状态、预期完成条件、观察到的行为、错误/求助、证据类型与设备。至少覆盖开始规划、补充信息、获取路线、辨别安全结论、切换方案、重新规划、地图不可用时继续阅读结果。

| 检查点 | 观察问题 |
| --- | --- |
| 字体与对比度 | 正文、次要说明、安全警示能否读清；测试环境与测量方式是什么？ |
| 点击目标与焦点 | 主要操作是否易点；键盘焦点是否可见，顺序是否符合阅读顺序？ |
| 信息密度与导航 | 用户能否找到下一步、路线和来源说明；是否须记忆前一屏内容？ |
| 认知负担 | 用户能否区分“查看中”和“推荐”、地面与空中、已知与未知？ |
| 动效与舒适度 | 相机移动、地图切换是否引起不适；是否可停止或退回平面/文字？ |
| 错误恢复 | 输入不清、网络断开或地图失败后，能否理解状态并继续操作？ |

有目标用户时记录样本、年龄/设备相关特征（避免无必要个人信息）、任务成功与误解，不把访谈印象当作量化总体结论。仅有审查或截图时写 `REVIEWER_EVIDENCE`，用户行为写 `REAL_USER_EVIDENCE`。
