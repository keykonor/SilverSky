# 2D / 3D 对照实验模板

## Research Question

3D 是否帮助目标用户理解 Ground–Air–Ground 阶段，并保持正确的安全与模拟理解？

## Hypothesis

预先写明预期改善指标和可能恶化的负担指标；不得把假设写成结果。

## Control

2D view。

## Treatment

3D Ground–Air–Ground view。

## Controlled Variables

两组使用**同一 `PlanningResult`**、相同路线卡、安全文案、任务、设备档次与操作说明；只改变视角。随机或平衡呈现顺序，记录学习效应。

## Tasks

让受试者找到路线、指出地面/空中换乘点、判断是否能实际乘坐、解释模拟与真实信息、在地图失败时找到文字结果；任务措辞不得先告知正确答案。

## Metrics

记录 Completion Time、Route Comprehension、Ground–Air Transition Accuracy、Simulation Misunderstanding Rate、Ease of Use、Visual Overload、3D Value、Motion Comfort；另记任务完成率、操作错误与求助。事先定义计时起止、正确答案、评分量表及异常处理。安全误解率是护栏，不可用更快耗时抵消。

## Sample

记录招募方式、人数、目标老人及子女分布、视力/设备与三维经验。

## Limitations

小样本只支持定性或探索性结论；缺真实用户参与时全部用户指标 `NOT_VERIFIED`。不能把 Agent 审查、截图或自动脚本记作受试者。

## Result

仅在对照数据支持预设收益且未增加安全误解或明显不适时写 `SUPPORTED`；证据不足、样本/测量不可靠写 `INCONCLUSIVE`；未达预设收益或伤害关键护栏写 `NOT_SUPPORTED`。报告同时给出 2D 与 3D 的数值、分母、差异及局限。
