# 无障碍证据层级

逐项记录设备、浏览器/系统、测试日期、步骤、结果与证据类型。任何未执行项目写 `NOT_VERIFIED`。

| 检查 | 可支持的证据 | 不可替代项 |
| --- | --- | --- |
| 键盘与焦点 | 实际 Tab、Enter、Space、Esc 操作及焦点顺序/可见性观察 | 静态截图或仅 DOM 检查 |
| 屏幕阅读器 | 指明真实阅读器、浏览器与任务，记录朗读顺序及操作结果 | axe 或 ARIA 属性存在性 |
| 浏览器缩放 | 原生 200% 缩放下完成核心任务、检查溢出与遮挡 | 改 CSS 视口或提高 DPR 的布局近似 |
| 对比度 | 实测前景/背景组合及交互状态 | 主观“看起来清楚” |
| 安全非颜色表达 | 在无颜色线索下能读出 `REJECT`、模拟、未知与降级 | 仅红/绿颜色或图标 |
| 动效舒适 | 目标用户或设备上的移动、视角切换观察 | 单帧截图 |

自动化检查标 `AUTOMATED_EVIDENCE`，评审观察标 `REVIEWER_EVIDENCE`，真实受试者行为标 `REAL_USER_EVIDENCE`。`PASS` 只覆盖已测任务与环境；关键目标环境缺失时总体为 `PARTIAL` 或 `FAIL`，并列明未验证范围。
