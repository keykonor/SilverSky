# SilverSky 空间数据与三维地图审查

先确认本轮地图目标及 `docs/INTERFACES.md` 的 V-001、A-001 契约，再核对实际输入、坐标转换、图层和截图。只审查有证据的行为；未知项保持待确认。

1. 核对每条线的 `Segment.geometry`、`geometry_status` 和 `geometry_evidence`。几何缺失或无效时保留文字说明，不用端点补画线路。真实道路快照、示意接驳、模拟空中走廊分别保留其来源标记。
2. 核对 WGS84 `[经度, 纬度]` 输入与显示提供方的坐标系。高德视图只接收转换成功的 GCJ-02 点；失败时不画未转换几何。检查城市和区划边界是否来自实际查询，不凭截图推断精度。
3. 核对地面与空中在视觉上可区分。空中曲线的高度只是模拟视觉高度，不传回规划结果、不用于安全或可飞性判断。地面高度与地形贴合、楼块和相机遮挡需通过实际场景检查，不能只凭 `z≈0` 或 `z>0` 推断正确。
4. 核对地图提供方、采集时间、许可、署名、覆盖范围和在线依赖；无法验证时标为待确认或 `DATA_UNAVAILABLE`。模拟起降点不得描述为真实设施。
5. 验证两城典型线路、视角复位、无几何、地图请求失败及降级状态；记录截图、测试结果和未测环境。上线、比赛许可与本地技术可用性分别报告。

涉及产品承诺或安全时遵循 `safety-data-integrity`；涉及接口变化时先遵循 `api-contract`。审查结果列出具体文件、可复现事实、影响和处理状态，不代替产品负责人批准地图提供方或真实运营信息。
