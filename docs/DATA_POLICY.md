# 数据来源与完整性规则

## 统一状态

| 状态 | 含义 | 对用户的表达 |
| --- | --- | --- |
| `VERIFIED` | 项目已核验来源、适用范围与时间的真实数据；只表示所记录字段已核验 | 显示来源和核验时间；不暗示实时或运营批准 |
| `PUBLIC_DATA` | 合法可用、有来源的公开真实数据，但项目尚未完成上述核验 | 显示公开来源和时间限制 |
| `SIMULATED_DATA` | 项目为演示构造的低空或其他模拟条件 | 显著标“模拟，不代表真实运营信息” |
| `DATA_UNAVAILABLE` | 没有足够可靠数据，或来源/使用条件无法确认 | 说明缺失内容和对规划的影响 |

`VERIFIED` 与 `PUBLIC_DATA` 不是航空适航、航班可售或监管许可状态。来源状态按**字段或路段**保留，路线汇总状态取最保守结果：出现 `DATA_UNAVAILABLE` 则为该状态；否则有 `SIMULATED_DATA` 则为模拟；否则有 `PUBLIC_DATA` 则为公开；全为已核验时才为 `VERIFIED`。可独立成立的纯地面路线按自身来源计算，不因另一条模拟候选受污染。

## 数据登记与使用

每个数据集登记来源、权利/使用条件、城市和地理范围、采集/更新时间、核验责任人、数据状态、模拟生成依据与失效条件。未登记使用条件的数据不得作为“可真实使用”数据输入规划。个人出行信息只收集任务所需字段；共享、留存与删除办法在接入用户数据前明确。

Golden 场景地面数据提供方已登记为 OSM POI 与 OSRM 道路模型快照；扩展城市或用途需另行核对使用条件。低空起降点、航线、航班和航空器状态均按模拟数据处理。天气、空域及运营状态若无可靠来源，返回 `DATA_UNAVAILABLE`。模拟路线不能推导出真实飞行可行性。

D-011 Golden 场景已登记天津、深圳四个 OSM POI 中心点和两条 OSRM 静态驾驶几何，均为 `PUBLIC_DATA`，来源与采集时间见 [DATA_SOURCES.md](DATA_SOURCES.md)。这些坐标不是出入口，静态几何不是实时、门到门或无障碍路线。受控别名仅定位 canonical POI，不提升位置精度。模拟起降点坐标、接驳直线和未来低空直线均为 `SIMULATED_DATA`；接驳距离/时间、真实天气与运营信息保持 `DATA_UNAVAILABLE`。`geometry_evidence` 单独说明几何真实性，不覆盖路段 `evidence`。

Sprint 3 的三维航迹高度只在前端由模拟几何派生用于展示；它不是批准高度、空域许可、飞行计划、运营参数或 Safety 输入。高德城市地图和可选 Cesium 地形/建筑只提供空间背景，不能改变 POI、线路和运营证据状态。高德视角中的模拟低空线是**地图投影**，仅 Cesium 视角显示模拟立体高度；两者都不证明航线可飞。高德失效回退 Cesium，本地底图和路线卡保留原有安全结论；来源与账户条件见 [DATA_SOURCES.md](DATA_SOURCES.md)。

## 传播与降级

工具响应、Agent 中间结果、API、路线卡、地图、报告都保留 `data_status` 与来源/时间说明。任何阶段不得删除模拟标记或把缺失值补成貌似真实的数据。影响安全或可达性的关键数据缺失时，Safety Review 应排除相关候选或标明无法确认；地面替代方案只有在其自身数据足够时才可推荐。
