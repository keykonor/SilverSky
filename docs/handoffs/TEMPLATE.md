# 交接模板（复制后删除提示）

日期 / 任务 / 负责人或来源：

## 目标与状态

一句话说明本轮目标、已完成/待验收/未完成，以及对应的 `PROJECT_STATE.md` 阶段状态；不把提交或测试通过写成阶段 PASS。

## 交付与决定

列出修改文件或提交哈希；说明关键决定及依据。跨模块接口写提供方、消费方、版本/兼容；无变化写“无”。数据/安全写真实与模拟来源、降级和用户可见限制；无影响写“无”。

## 验证与证据

表格列“命令或人工任务 / 环境与日期 / 结果 / 证据路径”。只记录实际执行；审查、自动化与真实用户证据分别标明。未运行的项目写 `NOT_VERIFIED` 和原因。

## 问题、未完成与接手

逐项列 P0/P1/P2、Blocker、待决与风险；每项写文件或场景、观察事实、影响、状态和建议负责人。给出下一步及接手时不得改变的范围或安全约束。

## 仓库资料审计

记录已跟踪/未跟踪文件盘点；说明本轮人工检查范围与方法、实际验证结果、未检查或无法验证范围。另设“发现的问题”清单，逐项列文件、事实、影响和状态；没有发现写“未发现”。
