# UX-3D-01 指标与评分

| 指标 | 计算与记录规则 |
| --- | --- |
| Completion Time | 视图稳定且开始阅读到六题答完的秒数；加载等待另计；未答完记超时与原因，不将其计为快速完成 |
| Route Comprehension Accuracy | 六题按预先标准逐题记 0/1，合计 0–6；需回答起点、A 换乘、B 下行、末段到终点、模拟性质、最缺运营/接驳/无障碍等现实证据 |
| Ground–Air Transition Accuracy | 第 2、3、4 题均正确且能按地面→空中→地面顺序复述记 1，否则 0 |
| Simulation Misunderstanding Rate | 将模拟航线/起降点当真实可运营的参与者数 ÷ 完成第 5 题的参与者数；分母 0 写 `NOT_VERIFIED`；这是 Safety 护栏 |
| Confidence | 1–5：“我认为自己理解了这条路线”；1 完全不同意，5 完全同意 |
| Ease of Use | 1–5：“这个页面容易使用”；同一量表 |
| Visual Overload | 1–5：“页面信息太多，让我难以理解”；高分更差 |
| 3D Value | B 后 1–5：“3D 帮助我理解了低空路线”；没有真实参与者时不得填数值 |
| Motion Comfort | B 后 1–5：“3D 镜头移动让我感到舒适”；低分更差；另记眩晕/暂停/退出 |

每位参与者 A/B 分开记录正确数、时间与操作错误，报告配对差异及原始分母；不合并 Reviewer 评价和真实用户数据。安全误解或晕动恶化不能由其他评分的提升抵消。若根本没有参与者，以上所有用户指标写 `NOT_VERIFIED`，不能填 0。
